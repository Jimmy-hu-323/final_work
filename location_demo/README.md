# LensGo 手机定位演示控制台

电脑上的独立小网页，通过 Type-C / ADB 给 Android 手机持续发送系统模拟位置。服务默认只监听 **http://127.0.0.1:18120**，不开放给局域网或公网。

本目录与 LensGo App 源码、后端业务独立；不改变 App 的任何页面或视觉展示，不读取聊天、真实手机坐标、密钥或私密 workspace，也不需要地图 API Key。

## 打开与关闭

1. 手机通过 Type-C 接电脑，解锁并允许 USB 调试，保持手机系统定位开启。
2. 双击本目录的 **`启动定位控制台.cmd`**。会隐藏启动本地 Python 后端，并在默认浏览器打开页面。重复启动会复用已运行的控制台。
3. 网页选择已连接的手机；可用“打开 LensGo 本地版”唤起 **LensGo 澳门旅游助手（本地版）**。
4. 演示结束，先在 App 结束旅程，再点网页顶部 **“恢复真实定位”**。网页后端可以保留运行。
5. 不再需要控制台时，双击 **`恢复定位并关闭.cmd`**，它会先恢复定位再关闭服务。恢复失败时保留服务及恢复记录，不强行结束进程。

默认使用项目已有 Python 环境：`../project_backend/middle_stage/Qwen_competion/.venv/Scripts/python.exe`，没有时使用 PATH 中的 `python.exe`。仅使用 Python 标准库（建议 3.10+），无 pip/npm 安装要求。ADB 优先从显式路径、`ADB_PATH`、PATH 或 Android SDK 目录寻找。

手动启动（PowerShell）：

```powershell
.\start.ps1 -NoBrowser
# 需要指定 ADB 时：
.\start.ps1 -AdbPath 'C:\Users\你的用户名\AppData\Local\Android\Sdk\platform-tools\adb.exe'
# 使用其他本机端口时，关闭也需指定相同端口：
.\start.ps1 -Port 18121
.\stop.ps1 -Port 18121
```

启动器的 ExecutionPolicy Bypass 仅用于当前 PowerShell 子进程，不修改电脑全局执行策略。

## 推荐演示流程

当前预设已扩充为 **25 个位置**：5 个酒店附近起点，以及半岛、氹仔/路氹、路环景点。使用“位置分类”筛选；列表可滚动。新增坐标来自项目公开景点种子目录（WGS84），是近似演示点，不代表酒店室内定位；出发地名称以地图实际识别结果为准。

1. 在控制台选 **“景点外 · 演示起点”**，点 **“开始模拟定位”**。
2. 也可以先选“酒店出发”中的位置。手机“旅程”点击“开始旅程”并允许定位，新弹窗先识别当前位置，再询问“接下来想去哪里”，列出附近 4 个候选地点、人数、直线距离及更新时间。绿色为较少、橙色为适中、红色为拥挤，缺失或超过 30 分钟的数据为灰色。选择目的地不改原行程；也可以先自由走走。保持 App 前台、手机亮屏；导览和附近检索需要后端与网络正常。
3. 在控制台点 **“大三巴牌坊”**，在同一位置停留约 30 秒，在手机“对话”观察是否自动创建景点讲解；再点附近美食或拍照打卡点进行展示。
4. 点 **“议事亭前地”**，继续停留并展示该景点讲解。新版按实际位置匹配当前行程及已加载客流目录中的已知景点，不限制计划日期或顺序，也不要求一定走向刚选的目的地。未收录地点不会凭空编造故事。相邻景点可能触发更近的一处；精确演示以 App 景点坐标为准。
5. 演示收尾：结束手机旅程，然后恢复真实定位。

已讲解过的景点有防重复触发；需要重新展示同一景点时使用新的演示行程，不要通过清除真实用户数据来重置。控制台不会替你创建/修改行程或清除触发记录。

控制台“发送次数”和停留进度只表示 ADB 已接受模拟位置指令，**不等于 App 已消费位置或成功触发故事**，最终需要观察手机。建议 30 秒不是业务保证时限；故事生成还取决于 Agent、网络等因素。

## 坐标与自定义位置

预设是演示用固定 WGS84 坐标，不是实时搜索的结果，也不保证匹配任意行程中同名景点的入口。

| 预设 | 纬度 WGS84 | 经度 WGS84 |
| --- | --- | --- |
| 景点外 · 演示起点 | 22.185000 | 113.530000 |
| 大三巴牌坊 | 22.197700 | 113.540800 |
| 议事亭前地 | 22.193500 | 113.539700 |

- GPS/WGS84 坐标选 `WGS84`；高德或 App 地图坐标选 `GCJ02`，后端会换算成 WGS84 再发给 Android。
- 注意输入框顺序是 **纬度、经度**，不是高德接口常用的“经度,纬度”。
- 填写经纬度和可选名称后点“应用自定义坐标”。未开始时只做预览；模拟中会立即切换并持续发送。
- 首次直接编辑坐标后点“开始模拟定位”也会使用已编辑的坐标。
- 页面示意图不是可点击取点地图，也不是导航地图；自定义位置不会伪装成示意图上的某个预设。
- 最可靠的演示坐标应以当前演示行程实际的景点坐标为准，并选对坐标系。

## 安全、范围与异常恢复

### 模拟位置源中途失效的处理（2026-08-29 修复）

- 已知错误“not a test provider”会触发一次安全重连并重发当前坐标；网页显示重连次数，停留进度重新计时。
- 重连前验证手机连接、系统定位、shell 模拟权限及其他模拟工具的授权。权限被撤销时不会自动重新授权；其他工具接管时不会覆盖或清除其位置源。
- 每分钟最多重连 3 次，反复失效、普通 ADB 错误或权限错误会停止并保留明确原因，不无限重试。操作记录保留中断原因，不再把恢复成功误写为“手机已重新连接”。
- 真实手机已验证一次模拟源丢失后自动恢复，随后持续发送超过 45 秒；黑沙海滩故事及追问选项已在 App 出现。完成验证后已恢复真实定位。
- 演示时保持手机亮屏、LensGo 在前台。当前行程已经讲解过的黑沙海滩不会再次自动新建故事；需要重复演示时使用新的演示行程，不要清除真实聊天或缓存。

- 模拟位置每 5 秒发送一次。只使用 Android 的 **network 测试 provider**，不关闭 GPS、不修改系统定位总开关，也不安装手机辅助 App。
- 仅针对已连接且已授权的 Android 设备；不是 iPhone 工具，也不保证所有厂商/Android 版本兼容。
- 模拟期间，手机上其他使用该位置源的应用也可能受影响；请勿同时用于导航、打车等依赖真实位置的活动。部分只使用 GPS 或自行检测 mock 的应用不一定采纳此位置。
- 开始前保存 shell 原始模拟定位权限；结束时移除本工具的 network 测试 provider 并恢复原权限。已有其他模拟定位工具授权时会拒绝接管。
- 网页每 5 秒发心跳。网页失联超过 90 秒，或单轮连续模拟达到 30 分钟，后端自动尝试恢复。后台浏览器节流可能触发超时；演示时建议保持控制台窗口可用。
- 拔线、关机、ADB 失联或强制杀掉后端时，**不能保证立刻恢复**。恢复记录会保存在 `.runtime/session.json`；重新连接原手机并保持调试授权，运行中的后端会重试，重启控制台也会先尝试清理遗留模拟状态。
- 恢复未完成时不要删除 `.runtime/session.json`，也不要启动另一套定位工具抢占；先连接原手机并重试恢复。恢复位置源不代表立刻收到新的真实 GPS fix，系统可能需要重新定位。
- 页面与接口仅限本机。修改操作需要正确的本机 Origin 和会话校验值；只允许预定义的 ADB 指令，不能输入任意 shell 命令。
- 本工具不读取或代理项目的 API Key、Token 或 App 私密数据。`.runtime` 只用于恢复记录和服务日志，已被本目录 `.gitignore` 排除；不要提交运行时文件。
- 控制台不会启动或重启原项目的其他后端；那些服务仍按根目录 `02_本地启动指南.md` 管理。USB 重连后如 App 无法访问后端，应按原项目方式恢复业务端口连接。
