## 去重规则

仅将 SHA-256 完全一致的文件视为同一图片，并复制一个规范副本。没有删除、移动或修改任何原文件。相似画面、不同分辨率、重新压缩或裁剪版本不会被自动删除，以免误伤；manifest.csv 的 pproximate_duplicate_note 列记录了这项规则。
