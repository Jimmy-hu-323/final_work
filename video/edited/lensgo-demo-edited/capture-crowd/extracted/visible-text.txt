[h2] 调用示例
[p] 发布数据：
[pre] curl -X POST http://47.82.123.50:18001/api/readings \
  -H "Content-Type: application/json" \
  -d '{
    "publisher": "sensor-sim",
    "note": "周末下午",
    "items": [
      { "region_id": "macau-poi-ruins-st-paul", "people_count": 860 },
      { "region_id": "macau-s-cunha", "people_count": 430, "crowd_level": 3 }
    ]
  }'
[p] 地图前端读取最新密度：
[pre] curl "http://47.82.123.50:18001/api/density/latest?city_id=macau&level=poi&include_empty=0"
[p] 返回结构（节选）：
[pre] {
  "generated_at": "2026-07-26T12:00:00Z",
  "count": 24,
  "items": [
    {
      "region_id": "macau-poi-ruins-st-paul",
      "name": "大三巴牌坊",
      "level": "poi",
      "parent_id": "macau-s-sao-paulo",
      "center": [113.5457, 22.1947],
      "coord_system": "gcj02",
      "radius_m": 120,
      "geometry": null,
      "reading": {
        "people_count": 860,
        "crowd_level": 3,
        "observed_at": "2026-07-26T11:58:00Z",
        "batch_id": "batch_9ae953c3aa39"
      }
    }
  ]
}
[code] reading
[code] null
[p] 表示该区域**没有数据**，
        请勿当作 0 人渲染。
[code] geometry
[p] 目前为 null，
        当前版本用
[code] center
[code] radius_m
[p] 作为落点，后续补入区域多边形后即可直接画色块。
