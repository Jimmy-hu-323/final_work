    新增区 / 街道 / 景点

    坐标可以填 WGS-84（从 GPS、维基、OSM 抄来的）或 GCJ-02（高德上取的）， 选对来源即可，服务端会统一转成 GCJ-02 入库。

    HTTP 接口

    所有响应都是 JSON。坐标一律为 GCJ-02 的 [lng, lat]，与主项目高德底图一致。 读接口默认公开；写接口在未设置 CROWD_WRITE_TOKEN 时只接受本机请求。

    方法路径说明
    GET/api/health服务状态与数据量统计
    GET/api/meta层级、拥挤度分级、推导阈值、当前权限
    GET/api/cities?q=搜索城市
    GET/api/regions?city_id=&level=&q=&limit=&offset=搜索区 / 街道 / 景点
    GET/api/regions/{id}区域详情
    GET/api/regions/{id}/history该区域的历史读数
    GET/api/density/latest?city_id=&level=&include_empty=地图页主接口：每区域最新密度
    GET/api/amap/status高德 Key 是否已配置
    GET/api/amap/search?q=&city=高德 POI 关键字搜索（服务端代理）
    GET/api/amap/around?lng=&lat=&radius=高德周边搜索
    GET/api/amap/regeo?lng=&lat=逆地理编码（坐标 → 地址）
    POST/api/regions/from-amap把高德地点登记为可发布区域（同一 POI 不重复建）
    POST/api/readings发布一批数据（一次 = 一个批次）
    GET/api/batches发布历史
    DELETE/api/batches/{id}撤销批次
    POST/api/cities / /api/regions新增城市 / 区域

    调用示例

    发布数据：

    curl -X POST http://47.82.123.50:18001/api/readings \
  -H "Content-Type: application/json" \
  -d '{
    "publisher": "sensor-sim",
    "note": "周末下午",
    "items": [
      { "region_id": "macau-poi-ruins-st-paul", "people_count": 860 },
      { "region_id": "macau-s-cunha", "people_count": 430, "crowd_level": 3 }
    ]
  }'

    地图前端读取最新密度：

    curl "http://47.82.123.50:18001/api/density/latest?city_id=macau&level=poi&include_empty=0"

    返回结构（节选）：

    {
  "generated_at": "2026-07-26T12:00:00Z",
  "count": 24,
  "items": [
    {
      "region_id": "macau-poi-ruins-st-paul",
      "name": "大三巴牌坊",
      "level": "poi",
      "parent_id": "macau-s-sao-paulo",
      "center": [113.5457, 22.1947],
      "coord_system": "gcj02",
      "radius_m": 120,
      "geometry": null,
      "reading": {
        "people_count": 860,
        "crowd_level": 3,
        "observed_at": "2026-07-26T11:58:00Z",
        "batch_id": "batch_9ae953c3aa39"
      }
    }
  ]
}

    reading 为 null 表示该区域**没有数据**， 请勿当作 0 人渲染。geometry 目前为 null， 当前版本用 center + radius_m 作为落点，后续补入区域多边形后即可直接画色块。
