# v1.2.0

发布日期：2026-09-02  
类型：新功能（向后兼容）

## 一句话

在人流数据发布器中加入“模拟巴士报站”：可以手动或自动发布车辆位置，并通过
HTTP API 读取下一站、剩余站数和模拟到站时间。

## 新增功能

- 新增“巴士报站”标签页。
- 内置 4 条澳门演示路线和有序站点。
- 可设置车辆编号、当前站、区间进度、状态、拥挤度、延误和速度。
- 支持单次发布、自动模拟、暂停和停止车辆。
- 自动模拟可以设置发布间隔和每站模拟用时。
- 当前车辆表展示下一站、预计到站、剩余站数、拥挤度和更新时间。

## 新增 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bus/routes` | 路线及有序站点 |
| GET | `/api/bus/routes/{route_id}` | 单条路线 |
| GET | `/api/bus/vehicles?route_id=` | 最新车辆状态 |
| POST | `/api/bus/vehicles` | 发布或更新车辆 |
| GET | `/api/bus/stops/{stop_id}/arrivals` | 站点到站预测 |

读取和发布分别复用现有 `crowd:read` 与 `crowd:publish` 权限，已有发布员账号不需要
重新配置权限。

## 数据库

启动时自动新增 `bus_routes`、`bus_stops`、`bus_route_stops`、`bus_vehicles` 和
`bus_vehicle_readings`，不会修改或清空现有人流数据。前者保存每辆车的最新状态，
后者保留每次发布历史。

## 真实性边界

当前路线、位置、到站时间和拥挤度全部为模拟数据。所有巴士接口均返回
`source: "mock"` 和免责声明，页面也固定展示醒目标识。数据不可作为实际乘车依据，
也不代表澳门交通事务局。
