## 发现但未修改的问题

1. 8 个行程中仅首个行程有费用，另外 7 个行程均为 0 项；历史行程不会自动生成预算明细。
2. 有 3 个行程同名为“1 天澳门行程”，选择器中无法区分。
3. Android 包版本仍为 `0.0.1/1`，与项目根版本基线 `v3.0.0` 不一致。
4. 首页写着“核心功能运行在这台手机，不需要电脑或云服务器”，但账单实际通过 `mobile_hotel_gateway` 访问 127.0.0.1:18088，并依赖电脑端 QwenPaw 与 hotel_book；当前文案会误导离线使用预期。
5. `adb reverse` 在拔线、重启手机或重启 ADB 后可能消失；再次联调前需要重建端口映射。
6. 日志有 WebView 的蓝牙权限、编解码器和系统反射警告，但本次账单流程不受影响。Android 构建也有 SDK XML/旧 Java API 警告，属于后续维护风险，不是当前运行故障。
