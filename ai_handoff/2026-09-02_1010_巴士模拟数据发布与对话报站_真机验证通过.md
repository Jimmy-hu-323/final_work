# 巴士模拟数据发布与对话报站：完成并真机验证

## 用户要求

把澳门“巴士报站”形式的功能融合到现有数据发布器。巴士数据允许编造，但需要能从发布器发布，并在 LensGo 对话公交导航中按线路和上车站匹配后显示。所有模拟内容必须明确标注，不能冒充真实实时公交数据。

## 完成内容

- 数据发布器升级到 v1.2.0，新增巴士线路、站点、线路站序、车辆状态和车辆历史读数表。
- 内置 61、3A、18、26A 四条澳门演示线路；数据均为模拟数据。
- 新增“巴士报站”页面，可选择线路和当前站、调整区间进度、速度、延误、载客状态，支持手动发布及自动推进模拟。
- 新增线路、车辆、车辆发布、站点到站预测 API；复用现有人流读写权限边界。
- QwenPaw 公交导航会用高德返回的线路号和上车站匹配发布器数据，匹配成功后把车辆、预计分钟、相隔站数、载客状态和延误附在对应公交段上。
- 手机“对话”在路演模式下以自然的“预计到站”展示车辆、时间、站数和载客情况，不在每条路线里重复技术性警告。数据发布器后台仍保留演示数据来源标识。发布器不可用或无匹配车辆时，原高德导航仍正常返回。

## 验证结果

- 数据发布器单元测试：7 项通过。
- 前端导航格式测试：8 项通过。
- JavaScript 语法检查、移动端 Web 构建和 Android arm64 Debug 构建均通过。
- APK 已覆盖安装到 Type-C 连接的 Android 手机，应用启动无崩溃。
- 远程发布器和 QwenPaw 服务均已部署并重启，原人流数据保留。
- 真实远程 HTTP 链路验证：从红街市附近规划到关闸总站，高德返回 61 路、上车站“青茂/何贤绅士马路”；后端匹配到模拟车辆 `server-demo-61-01`，返回约 2 分钟、1 站。
- 真机“对话”实际显示同一条 61 路“预计到站：server-demo-61-01：约 2 分钟，1 站，车内较少”，且没有重复警告。测试时临时替换的行程位置已恢复为原值。
