# 对话界面多会话与模型选择实机验证

## 用户目标与范围

- 仅调整手机端“对话”栏目内部的界面和聊天相关能力，其他栏目不得因本任务发生界面变化。
- 对话页改为参考图所示的白色简洁布局：顶部模型、新建、历史入口固定；消息区域独立滚动；输入框固定在底部导航栏上方并保持小间距。
- 模型选择器读取当前已配置 API 所提供的模型；“+”新建独立聊天；“...”打开历史聊天并支持恢复。
- 完成 Android 构建、Type-C 真机安装和交互验证。

## 修改文件与关键改动

后端交付树与前端镜像树同步修改了以下五类文件：

- `project_backend/middle_stage/Qwen_competion/qwen_compitition/console/src/mobile-local/MobileLocalApp.tsx`
- `project_backend/middle_stage/Qwen_competion/qwen_compitition/console/src/mobile-local/mobileLocal.module.less`
- `project_backend/middle_stage/Qwen_competion/qwen_compitition/console/src/mobile-local/runtime.ts`

- `project_backend/middle_stage/Qwen_competion/qwen_compitition/console/src-tauri/src/lib.rs`
- `project_front/middle_stage/Qwen_competion/qwen_compitition/console/` 下对应镜像文件。

主要实现：

1. 对话页使用专属固定顶栏、独立消息滚动区和固定底部输入区；样式类均限定在对话页。
2. 新增本机多会话存储，旧版单会话消息自动迁移并保留；每个会话分别保存标题、消息、所选模型及远端会话 ID，最多保留 50 条。
3. “+”创建空白新聊天；“...”打开右侧历史抽屉，可恢复或删除会话。
4. 模型选择包含 QwenPaw 主智能体，以及原生端通过当前已配置 API 的 OpenAI 兼容 `/models` 接口取得的模型。API Key 始终留在原生层，没有暴露给 WebView。
5. 直连 API 聊天允许按会话传入模型覆盖值；未选择时继续使用原配置模型。QwenPaw 原有流式链路保持不变。
6. 后端树与前端镜像的四个对应源码文件内容哈希一致；`mobile_runtime.rs` 因后端树保留了此前账单相关改动，不应直接整文件覆盖。

## 风险与后续注意

- 模型发现依赖供应商提供 OpenAI 兼容 `/models` 接口；若接口不可用，界面会回退显示当前配置模型，聊天仍可使用原配置。
- 多会话历史存储在手机应用本地，卸载应用或清除应用数据会删除这些历史。
- USB 断开、手机或 ADB 重启后，`adb reverse` 可能失效，联调前应重新检查。
- 工作区原本已有账单页、旅程页及旧交接文件等未提交改动，本任务全部保留，未回退或覆盖。不要把本次对话改动与这些既有改动混淆。
- `cargo fmt --check` 仍会报告 `backend/command.rs`、`backend_download.rs` 的既有格式差异；本任务未修改这两个文件。
