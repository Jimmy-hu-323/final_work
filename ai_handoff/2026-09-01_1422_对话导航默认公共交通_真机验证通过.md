# 对话导航默认公共交通：完成并真机验证

## 需求结果

- 用户在“对话”中直接询问“怎么去某地”时，默认使用公共交通，不再默认驾车。
- 明确说“步行、走路、徒步”时仍规划步行路线。
- 明确说“驾车、开车、打车、的士、出租车、坐车”时仍规划驾车路线。
- 回答中的出行方式、高德地图跳转模式、服务器路线查询三处保持一致。

## 实现范围

- 两份移动端镜像的 `chatNavigation.ts`：增加 `transit` 模式、意图优先级、公共交通文案和高德 `mode=bus` 跳转。
- 两份移动端镜像的 `runtime.ts`：导航响应和请求类型支持 `transit`。
- 两份 Tauri `mobile_runtime.rs`：对话导航缺省模式改为 `transit`，不影响行程地图原有驾车/步行逻辑。
- Python 后端 `travel_planner.py`：对话导航支持高德公共交通综合路线接口，解析步行、巴士、轨道交通、距离、时间及折线点。
- 前后端测试已补充默认公共交通与显式驾车/步行覆盖。

## 验证记录

- Python 导航测试：17 项通过。
- 前端导航测试：8 项通过。
- 后端结构集成测试：11 项通过。

- 手机“对话”真机发送“从当前位置怎么去大三巴牌坊？”，回答显示“出行方式：公共交通”，并返回实际路线、预计时间和高德导航入口。
